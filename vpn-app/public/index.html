VPN Manager

Бесплатный менеджер VPN-подключений через WireGuard.

Бесплатный VPN через Oracle Cloud

1

Зарегистрируйтесь в Oracle Cloud

Создайте аккаунт на cloud.oracle.com (нужна карта, но списаний нет — всегда бесплатный тариф).

2

Создайте VM в нужном регионе

Выберите регион (США, Нидерланды, Япония, Южная Корея и др.) → Create VM Instance → Canonical Ubuntu — всегда бесплатно.

3

Откройте порт WireGuard

В VCN → Security List добавьте Ingress Rule: UDP 51820, Source 0.0.0.0/0.

4

Подключитесь к серверу (SSH)

Используйте SSH-ключ, скачанный при создании VM.

ssh -i ключ.key ubuntu@<IP-сервера>
5

Установите WireGuard одной командой

Скопируйте и запустите эту команду на сервере:

curl -sL https://raw.githubusercontent.com/ ваш-скрипт/main/setup-server.sh | bash

Скрипт сам установит WireGuard, сгенерирует ключи и выведет готовый конфиг.

6

Скопируйте конфиг в приложение
